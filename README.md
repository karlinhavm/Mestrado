#replication-repository/Master's
This repository contains the supporting materials, executables, and configuration files related to the master's research conducted by Karlinha VM. The purpose of this repository is to ensure methodological transparency and enable the replication of the computational procedures used in the study.

## Repository Structure

- /plugin: Contains the executable file (.exe) developed by the lab to automate and standardize image preprocessing.

## About the Tool

The batch processing utility in this repository was developed in-house by the lab to automate crucial tasks in the methodology, performing the following operations on images in a standardized manner:
1. Inversion
2. Mirroring
3. Conversion to grayscale

## How to Use and Replicate

1. Access the */plugin* folder and download the executable file provided.
2. Run the utility on your machine following the methodological parameters described in the dissertation to reproduce the same image processing pipeline.
